POC on Automated Vulnerability Remediation

Introduction

This Proof of Concept (POC) demonstrates how AI-powered automation can streamline software maintenance and release management by reducing manual effort across key development activities. The solution leverages Microsoft Copilot to automate feature branch creation, code synchronization, and vulnerable JAR library updates, while integrating modern deployment practices through Harness LightSpeed. It also outlines a future roadmap for continuous dependency management using Renovate, enabling faster, more secure, and efficient software delivery

Automated Release Branch Creation and Code Sync

Using Microsoft Copilot, automate the creation of feature branches for each monthly release and code synchronization from the master branch to the feature branch, significantly reducing the manual effort involved in the release process

Automated Jar library update

Build a .csv or .xlsxl sheet containing vulnerable JAR libraries and their corresponding GOTO versions for each application component based on Archer reports.

Sharing prepared sheet to Microsoft Copilot enabled with Enterprise Data protection to automatically replace the outdated JAR libraries with the latest ones across multiple application components.

LightSpeed Deployment Integration

Integrated LightSpeed deployment using Harness, replacing the traditional CI/CD approach and skipping Jenkins build generation before RLM deployment.

Renovate - Automated Dependency Update AI Agent

  • Continuously scans Maven, Docker and other ecosystems.
  • Automatically creates Pull Requests.
  • Applies the latest dependency security patches.
  • Reduces technical debt by keeping dependencies up to date.
