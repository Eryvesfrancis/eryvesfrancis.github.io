Automated JAR Library Vulnerability Remediation Solution

Objective

To eliminate manual updates of vulnerable JAR versions across multiple application components using GitHub Copilot with Enterprise Data Protection.

Inputs

Build an Excel sheet containing vulnerable JAR libraries and their corresponding GOTO versions for every application component based on Archer reports.

Current Enhancements

Integrated LightSpeed deployment using Harness, replacing the traditional CI/CD approach and skipping Jenkins build generation before RLM deployment.

Future Enhancements

Renovate - Automated Dependency Update Agent

  • Continuously scans Maven, Docker and other ecosystems.
  • Automatically creates Pull Requests.
  • Applies latest dependency security patches.
  • Reduces technical debt.
