Automated JAR Library Vulnerability Remediation Solution

Problem Statement

Instead of manually creating feature branches for every release, we have automated feature branch creation and code synchronization from the master branch.

For every vulnerable JAR version upgrade, developers manually update Maven dependency versions across multiple application components.

Objectives

Eliminate manual updates of vulnerable JAR versions across multiple application components using GitHub Copilot with Enterprise Data Protection.

Inputs

Build an Excel sheet containing vulnerable JAR libraries and their corresponding GOTO versions for each application component based on Archer reports.

Current Enhancements

Integrated LightSpeed deployment using Harness, replacing the traditional CI/CD approach and skipping Jenkins build generation before RLM deployment.

Future Enhancements

Renovate - Automated Dependency Update Agent

  • Continuously scans Maven, Docker and other ecosystems.
  • Automatically creates Pull Requests.
  • Applies the latest dependency security patches.
  • Reduces technical debt by keeping dependencies up to date.
